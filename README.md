# 👋 Get to Know Me Program (C++)

## 📖 Description
This is a simple C++ program that introduces myself using functions. It demonstrates the basics of function creation, function calls, and formatted console output.

## 💻 Features
- Displays a program header.
- Shows my personal profile.
- Displays a thank-you footer.
- Uses separate functions to organize the code.

## 🛠️ Technologies Used
- C++
- iostream library

## 📂 Program Structure
- `displayHeader()` – Prints the program title.
- `displayProfile()` – Displays my personal information.
- `displayFooter()` – Prints the closing message.
- `main()` – Calls all functions in order.
